
## Getting Started 🚀

### Download & Use

1. **Clone from GitHub:**
```bash
git clone https://github.com/tastespiccec-source/TNS.git
cd TNS
```

2. **Open in FlutterFlow:**
   - Visit [FlutterFlow.io](https://flutterflow.io)
   - Import the project files

3. **Build APK (Android):**
   - Click "Build" in FlutterFlow
   - Download the APK
   - Install on your phone

4. **For iOS:**
   - Publish on TestFlight or App Store
